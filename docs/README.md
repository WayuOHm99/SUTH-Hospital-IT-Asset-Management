# Documentation

- `architecture/` — ภาพรวมระบบ โครงสร้าง และ interfaces สำคัญ
- `handoff/` — สถานะสำหรับส่งมอบงานให้ทีม
- `fixes/` — บันทึกสาเหตุและวิธี deploy ของการแก้ปัญหาสำคัญ
- `samples/` — ไฟล์ตัวอย่างสำหรับทดสอบกระบวนการนำเข้า ห้ามใส่ข้อมูล production

คำสั่งติดตั้งหลักและลำดับ migration อยู่ที่ [`../README.md`](../README.md)
