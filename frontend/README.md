# Frontend

Vue 3 single-page application สำหรับ SUTH Hospital IT Asset Management

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

Development server เริ่มต้นที่ `http://localhost:5173` และเรียก Express API
ที่ `http://localhost:3000` ผ่าน `src/services/api.js`

โครงสร้างและขั้นตอนติดตั้งระบบทั้งหมดอยู่ที่ [`../README.md`](../README.md)
