# Claude Repository Handoff

Read and follow `AGENTS.md` before taking any action. The shared automation
protocol is in `docs/agents/automation.md`.

Key constraints:

- Work on exactly one GitHub Issue and one dedicated branch at a time.
- Never edit a checkout currently used by another agent.
- Stop before schema/migration, auth, security, secrets, destructive,
  deployment, or production work unless a human has added `human-approved`.
- Open a pull request, respond to `codex-changes-requested`, and never merge.
